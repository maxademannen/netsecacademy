# Network Ninja Academy

I want to make an interactive learning program for network security. Like a complete duolingo-esque site that contains theoretical courses, practical labs, quizzes/tests and more, that goes from basic to advanced in knowledge of network security. My goal is to make an IDS, so ideally it should be building to that, but offensive security and the like should also be included. You need to know how to break something to learn what makes it... not broken, no?
